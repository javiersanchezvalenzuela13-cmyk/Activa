# Activa
## Proyecto grupal Desarrollo de Interfaces 
Aplicación de escritorio desarrollada en **JavaFx**, **Maven** y **MySQL** para la gestión, consulta e inscripción a actividades comunitarias.

## Requisitos previos
- **Java Development Kit (JDK): ** Versión 17 o superior.
- **Apache Maven:** Versión 3.8+ (incluido por defecto en IntelliJ IDEA).
- **MySQL Server:** Versión 8.0 o superior.
